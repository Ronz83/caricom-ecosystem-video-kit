# Complete 8-Video Scripts & Scene Breakdown

> **Root Cause of Mid-Sentence Language Switch:** Microsoft Edge TTS `*MultilingualNeural` voices (`en-US-AndrewMultilingualNeural`, `en-US-AvaMultilingualNeural`, etc.) run an automatic language detector on every clause. When they hit regional brand tokens like `CARICOM`, `CARI`, `CariPass`, `CariSplit`, or `Cap. 317`, the multilingual model misclassifies the clause as Spanish/French/Portuguese and switches language mid-sentence. Switching the voice ID to strict monolingual English voices (`en-US-ChristopherNeural`, `en-US-AriaNeural`, `en-US-GuyNeural`, `en-US-JennyNeural`) locks the phoneme engine to 100% English.
